# 无限画布功能与接入说明

本次按 2026-09-15 的上游功能对比实现，继续使用 Go/Vite、Cookie 身份和统一的创作任务、文件存储接口。原始差异与触发条件见 [对比记录](../review/infinite-canvas-comparison-2026-09-15.md)，完成证据见 [执行记录](../review/infinite-canvas-alignment-progress.md)。

## Agent 与 Skill

- Agent 默认先建立节点、连接和生成参数。检查后在节点上点击生成；需要连续自动生成时，在 Agent 的“运行设置”打开“自动生成媒体”。
- 内置 Agent 支持 Chat 和 Responses，深入思考使用 Responses。Responses 保留推理和工具调用的完整回放；输出被截断时不会执行不完整的动作。
- 工具参数使用严格 JSON、字段和类型校验；错误会给模型一次纠正机会。长会话按完整轮次总结，大画布可以分页检索节点，结果支持定位节点。
- “Skill → 管理”可创建、编辑、导入个人 Markdown 规则；管理员也可管理系统 Skill 及 Markdown/TXT 附属文件。每个会话最多选择 5 个，附件只允许读取当前选中的 Skill。
- 可以复制消息、重命名对话。从首页选择的 Skill 会带入新画布；在画布中主动新建对话时清空所选 Skill。
- Codex 引擎、外部 MCP 和连接插件的安装、端口、权限及验证见 [本地服务说明](../canvas-agent/README.md)。连接需要自己的 Codex CLI 登录态；媒体生成仍使用当前画布账号配置的线路。

## 画布、素材与文件

- 在已有图片节点上继续生成时，会合并自身图片和连线参考，保持引用顺序。
- 视频取消选中后暂停。视频获得焦点后仍可使用画布复制、粘贴、删除快捷键，输入框继续保留自己的编辑行为。
- 视频操作提供首帧、当前帧、尾帧截图和分离音频；音频可选择范围、试听和截取，结果另建节点。浏览器必须支持源文件的编码，无法解码时会显示错误。
- 节点列表按画布分组显示树形结构，可以折叠。生成期间节点显示进度；上游未提供百分比时不伪造确定进度。
- 素材的分组统一称为标签，同一素材可属于多个标签。历史分组和旧 tags 合并到现有分组关系；编辑素材不会清空归属。素材页、画布选择器和侧栏可按标签筛选。
- 手填媒体 URL 会尝试读取 MIME、大小、宽高等信息。读取受浏览器跨域权限约束；修改 URL、切换账号或关闭编辑后，旧请求结果不会覆盖新表单。
- Chat/Responses 图片编辑可直接复用外部公网参考 URL，并保留与上传文件混合后的顺序。Images 模式及需要登录访问的文件继续上传内容，局部遮罩编辑需要上传参考图片。URL 直传本身不能保证上游有权访问该远端站点。
- WebDAV 上传的 MP4 即使名称没有扩展名或为 `.bin`，也保存为 `.mp4`。

统一存储中的文件失去素材、项目、工作流、对话和任务引用后，会进入持久回收队列，持续 24 小时无引用才删除。浏览器撤销和重做历史持有 24 小时租约，页面可见时每 30 分钟续期；租约过期后清除旧撤销历史。服务端不会续期过期声明，延迟完成的生成也不会恢复旧历史。回收还识别公开存储 URL、对话内链接和序列化工具结果。扫描失败时不删除，提供商失败会重试，每轮最多删除 32 个对象。Direct WebDAV 只回收索引，不删除外部原文件。旧专属图片/音视频目录继续使用原有保留期治理。

## AutoDL ComfyUI

1. 个人设置的自定义 API 配置中选择“AutoDL ComfyUI 工作流”，填写 Base URL（例如 `https://autodl.art`）和自己的 Token；视频、音频分别建立对应类型的线路。
2. 从该线路读取模型目录，将所需工作流 ID 加入对应模型配置，画布才能选择。
3. 视频模型契约中点击“从 AutoDL 导入”，选择线路及工作流，检查草稿后发布。无法从输入规则确定时长等能力时，需要补完契约。
4. 画布会读取工作流参数。提示词及连线素材自动传入，随机种子、参考素材和情感等额外参数可在节点中填写；必填项、枚举和范围按工作流实际规则校验。

目录和详情使用公开元数据缓存，生成任务使用个人 Token。已读取真实公开目录和 H3、IndexTTS 详情，证据见 [协议验证](../review/autodl-ark-protocol-validation-2026-09-15.md)。这不等于真实生成、账号额度或下载链路已验证。

## 方舟 Seedance 与 Agent Plan

个人设置中创建视频线路，协议选择“火山方舟 Seedance 原生协议”。标准 API 的 Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`；Agent Plan 为 `https://ark.cn-beijing.volces.com/api/plan/v3`。不要追加具体任务接口路径。

模型目录未提供 `/models` 时按套餐手动填写模型 ID，并在视频契约中配置该模型的时长、分辨率、素材能力与原生驱动。请求以带 role 的混合 content 发送首尾帧、参考图片、视频和音频。标准 API 与 Agent Plan 已通过 HTTP 模拟测试，尚未调用付费方舟生成。

AutoDL 和方舟需要能从外部访问参考素材。本地受 Cookie 保护的文件经现有参考上传接口转换为限时签名地址；实际部署地址须能被上游访问。

桌面端可使用内置本地服务，也可连接已有服务器；本地数据与服务器数据各自在其运行位置保存。开发、打包、首次账号设置和验证边界见 [Windows 桌面说明](windows-desktop.md)。
