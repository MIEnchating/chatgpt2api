# 无限画布功能与接入说明

本次按 2026-09-15 的上游功能对比实现，继续使用 Go/Vite、Cookie 身份和统一的创作任务、文件存储接口。原始差异与触发条件见 [对比记录](../review/infinite-canvas-comparison-2026-09-15.md)，完成证据见 [执行记录](../review/infinite-canvas-alignment-progress.md)。

## Agent 与 Skill

- Agent 默认先建立节点、连接和生成参数。检查后在节点上点击生成；需要连续自动生成时，在 Agent 的“运行设置”打开“自动生成媒体”。
- 内置 Agent 支持 Chat 和 Responses，深入思考使用 Responses。运行设置中的“流式响应”默认开启，已明确保存的关闭设置继续保留；带工具的请求同样遵守该设置，不强制关闭流式。分段接收模型输出，完成后展示回复并执行工具；该设置也应用于长期记忆摘要。关闭深入思考时，GPT-6 Astra 和 GPT-6.1 Sol 使用支持的 low，其他模型使用 none。Responses 保留推理和工具调用的完整回放；输出被截断或流缺少完成标记时不会执行不完整的动作。
- 工具参数使用严格 JSON、字段和类型校验；错误会给模型一次纠正机会。长会话按完整轮次总结，大画布可以分页检索节点，结果支持定位节点。
- “Skill → 管理”可创建、编辑、导入个人 Markdown 规则；管理员也可管理系统 Skill 及 Markdown/TXT 附属文件。每个会话最多选择 5 个，附件只允许读取当前选中的 Skill。
- 可以复制消息、重命名对话。从首页选择的 Skill 会带入新画布；在画布中主动新建对话时清空所选 Skill。
- Codex 引擎、外部 MCP 和连接插件的安装、端口、权限及验证见 [本地服务说明](../canvas-agent/README.md)。连接需要自己的 Codex CLI 登录态；媒体生成仍使用当前画布账号配置的线路。

## 画布、素材与文件

- 在已有图片节点上继续生成时，会合并自身图片和连线参考，保持引用顺序。
- 视频取消选中后暂停。视频获得焦点后仍可使用画布复制、粘贴、删除快捷键，输入框继续保留自己的编辑行为。
- 视频操作提供首帧、当前帧、尾帧截图和分离音频；音频可选择范围、试听和截取，结果另建节点。浏览器必须支持源文件的编码，无法解码时会显示错误。
- 节点列表按画布分组显示树形结构，可以折叠。生成期间节点显示进度；上游未提供百分比时不伪造确定进度。
- 素材的分组统一称为标签，同一素材可属于多个标签。历史分组和旧 tags 合并到现有分组关系；编辑素材不会清空归属。素材页、画布选择器和侧栏可按标签筛选。
- 手填媒体 URL 会尝试读取 MIME、大小、宽高等信息。读取受浏览器跨域权限约束；修改 URL、切换账号或关闭编辑后，旧请求结果不会覆盖新表单。
- Chat/Responses 图片编辑可直接复用外部公网参考 URL，并保留与上传文件混合后的顺序。Images 模式及需要登录访问的文件继续上传内容，局部遮罩编辑需要上传参考图片。URL 直传本身不能保证上游有权访问该远端站点。
- WebDAV 上传的 MP4 即使名称没有扩展名或为 `.bin`，也保存为 `.mp4`。

统一存储中的文件失去素材、项目、工作流、对话和任务引用后，会进入持久回收队列，持续 24 小时无引用才删除。浏览器撤销和重做历史持有 24 小时租约，页面可见时每 30 分钟续期；租约过期后清除旧撤销历史。服务端不会续期过期声明，延迟完成的生成也不会恢复旧历史。回收还识别公开存储 URL、对话内链接和序列化工具结果。扫描失败时不删除，提供商失败会重试，每轮最多删除 32 个对象。Direct WebDAV 只回收索引，不删除外部原文件。旧专属图片/音视频目录继续使用原有保留期治理。

## AutoDL ComfyUI

1. 个人设置的自定义 API 配置中选择“AutoDL ComfyUI 工作流”，填写 Base URL（例如 `https://autodl.art`）和自己的 Token；视频、音频分别建立对应类型的线路。
2. 从该线路读取模型目录，将所需工作流 ID 加入对应模型配置，画布才能选择。
3. 视频模型契约中点击“从 AutoDL 导入”，选择线路及工作流，检查草稿后发布。无法从输入规则确定时长等能力时，需要补完契约。
4. 画布会读取工作流参数。提示词及连线素材自动传入，随机种子、参考素材和情感等额外参数可在节点中填写；必填项、枚举和范围按工作流实际规则校验。

目录和详情使用公开元数据缓存，生成任务使用个人 Token。已读取真实公开目录和 H3、IndexTTS 详情，证据见 [协议验证](../review/autodl-ark-protocol-validation-2026-09-15.md)。这不等于真实生成、账号额度或下载链路已验证。

## 方舟 Seedance 与 Agent Plan

个人设置中创建视频线路，协议选择“火山方舟 Seedance 原生协议”。标准 API 的 Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`；Agent Plan 为 `https://ark.cn-beijing.volces.com/api/plan/v3`。不要追加具体任务接口路径。

Agent Plan 使用内置候选列表（2026-09-17 上游目录）：原生视频线路提供 5 个视频候选，Chat/Responses 自定义线路提供 17 个候选，由模型设置按类型筛选。这是选择辅助，不代表 Key 验证通过或账号已开通；实际模型以套餐为准，也可手动填写模型 ID。标准 API 仍请求真实 `/models`。视频契约中仍需配置模型的时长、分辨率、素材能力与原生驱动。请求以带 role 的混合 content 发送首尾帧、参考图片、视频和音频。标准 API 与 Agent Plan 已通过 HTTP 模拟测试，尚未调用付费方舟生成。

AutoDL 和方舟需要能从外部访问参考素材。本地受 Cookie 保护的文件经现有参考上传接口转换为限时签名地址；实际部署地址须能被上游访问。

## Windows 桌面

桌面端可使用内置本地服务，也可连接已有服务器；本地数据与服务器数据各自在其运行位置保存。开发、打包、首次账号设置和验证边界见 [Windows 桌面说明](windows-desktop.md)。

## 2026-10-08 上游功能对齐

参考 `tigerowo/infinite-canvas` 的 `c51c49d2110e84c6dabefba6480df8561bc3eed5`，在现有 Go/Vite 架构中实现图片、视频和音频渠道的自定义请求/响应转换、异步查询和管理员默认规则编辑器。规则支持语法校验、高亮预览、变量插入和复制配置说明，使用方式与任务生命周期边界见 [渠道参数转换](channel-parameter-translation.md)。之后移除个人自定义 API 渠道的独立规则配置，管理员默认规则仍保留。同时补充 `sd2` 视频短名识别，修复手动插入画布引用时遗漏 `@` 的显示问题。

## 2026-10-19 上游功能对齐

参考上游 `ccda172efba25cbee990a785bba715b90cc42b95`（2026-10-18），将以下变化接入现有 Go/Vite 和创作任务接口：

- 图片工作台的结果工具栏提供“局部重绘”：涂抹区域、填写修改要求后提交。复用画布遮罩编辑器，继承原任务的模型、尺寸、质量、输出格式和渠道等配置，保存为同一会话的新一轮任务，每次生成一张，原图和原记录保留。可以在弹窗切换支持参考图的模型。
- 历史侧栏提供“批量下载”：选择多个会话，将已完成的图片和视频按会话、轮次打包为 ZIP；“全选已加载”只选当前已加载的历史。下载过程中可取消，单包最多 1 GiB，读取失败会提示重试，不静默遗漏文件。
- 管理员默认转换规则的 `aspectRatio` 从像素尺寸约分为比例，例如 `1536x1024` 变为 `3:2`，显式比例优先。视频 Base64 响应先保存到视频目录，任务结果只存文件地址。
- 工作台及画布的停止按钮在服务端停止失败后提供“重试停止”，只重试失败的任务。画布停止后才收到提交确认时补发停止请求；重试及迟到确认绑定发起任务时的账号。

本地已有串行自动保存、数据库事务回滚和服务端任务轮询机制，不重复移植上游的 Next.js/SQLite 实现。AutoDL 输出已限定公网 HTTP(S) URL，未发现相同的 Base64 视频入库路径。真实 AutoDL/方舟付费生成不在本次回归验证范围内。


## 2026-10-27 上游功能对齐

参考 `tigerowo/infinite-canvas` 的 `e13006fbaeabe14e4a6d27cba667ff1473009ebc`，相对上次基准新增 3 个提交。本轮继续在 Go/Vite 架构中实现：

- 个人中心的创作偏好增加“已有内容的节点再次生成时”：选择覆盖当前节点或新建衍生节点，默认新建衍生节点。适用于图片、视频、音频、文字和全景图；配置节点始终创建输出节点，失败重试仍更新原任务节点。局部编辑和多角度操作继续保留原图并创建结果节点。
- 视频同步声音使用现有工作台偏好作为统一默认值，个人中心可以修改，画布新建视频节点和 Agent 规划继承此值；已有节点保留显式选项，模型不支持声音时不发送开启参数。
- 切换空白节点比例、生成结果比例变化时以当前长边计算尺寸，保留中心位置，避免节点反复变小。媒体加载按真实尺寸纠正显示比例，过期 URL 的加载事件不覆盖新结果，自由缩放保留用户尺寸。
- Agent/节点提示词中的引用复制为带 `@` 的文本；配置节点复制时将内部引用 ID 转换为当前素材编号，避免复制出图标、删除按钮文字。

节点参数抽屉和双击菜单已在画布缩放层外，无需重复加入反向缩放。管理员 WebDAV 原本已支持内网地址，个人 WebDAV 继续使用公网访问限制；设置页补充说明。TokenDance 相关调整不纳入。

## 2026-11-05 上游功能对齐

参考 `tigerowo/infinite-canvas` 从 `e13006fbaeabe14e4a6d27cba667ff1473009ebc` 到 `a166ac8ab8fe7a94eeb45043883eb0e5135d46e6` 的 11 个提交。按本项目 Go/Vite 架构移植，视频按分辨率计费和 TokenDance 变动不纳入。

- 画布和图片结果预览使用本地 WebP 缓存，最长边 768 像素，最多 256 项、保留 7 天，账号变化时清理。预览保留原始宽高和文件大小；生成、下载、编辑和画布导出继续使用原图。
- 画布上传和拖拽支持一次选择多份图片、视频、音频，依次上传并排列；切换项目或账号后停止剩余上传。拖动节点时显示边缘和中心对齐辅助线并吸附，开启网格吸附时优先网格。视野外连线不再绘制，穿过视野的连线仍保留。
- 视频时长增加滑块，按模型契约的合法时长选项或步长调整；智能时长独立切换。素材选择器支持同时选择多个标签，命中任一标签即可显示，仍沿用已有分组关系，不增加第二套分类。
- MiniMax `speech-*` 音频模型支持同步语音生成、系统音色读取、自定义音色 ID、MP3/WAV/FLAC 和 0.5–2 倍语速。沿用现有音频渠道与个人默认参数；上游失败状态、无效音频编码和超大响应会明确报错。
- 管理员及个人 S3 配置增加“Bucket 使用子域名”，Endpoint 填写不含桶名的服务地址；上传签名使用真实 SHA-256 摘要，适配拒绝 `UNSIGNED-PAYLOAD` 的服务。WebDAV 修复中文、空格、百分号等路径被重复编码的问题。
- 画布新增菜单、素材新增表单提供“临时公网上传（7 天）”，明确提示文件发送至 tmpfile.link、持链接者可访问、单文件最多 100 MB。本站接口仍要求登录，仅接收媒体文件，不转发用户登录凭据；此入口不会自动替换正常存储方式。
- 修复 Agnes 2.5 图片分辨率及比例参数，并过滤 Gemini 返回的 `thought` 图片，避免把思考过程中的图片当成最终结果。

现有实现已具备系统提示词传递、Grok 视频公网参考 URL 保留、日志清除筛选，以及有明确大小限制的响应读取。上游 GORM 字段/索引和初始化修复不直接适用于本项目存储层，未复制其数据库模型或迁移。

验证使用隔离 Go 测试与 Chromium/Firefox 模拟接口，未调用真实付费生成，也未向真实 S3、WebDAV 或 tmpfile.link 上传用户文件。
