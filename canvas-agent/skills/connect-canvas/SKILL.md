name: connect-canvas
description: 连接并操作云棉（chatgpt2api）画布，用于打开目标画布、检查本机 MCP 连接、检索节点及执行用户要求的创作操作。
---

优先复用当前任务明确指定的画布 URL 或可控浏览器中现有的云棉标签。多个目标无法区分时只询问目标画布；不要从其他任务推断账号或项目。

先读取插件根目录的 [连接说明](../../README.md)，其中包含本机服务命令、准确 Origin、MCP 环境变量和当前协议。已有同用途服务与浏览器标签应直接复用；只在缺少服务时启动，并记录本任务启动的进程。对浏览器使用当前可用的浏览器工具；不具备浏览器控制能力时给出目标链接和所需页面操作。

连接使用当前登录网页。在 Agent 面板选择 Codex，填写本机服务地址和终端连接密钥，连接后复制 MCP 连接 ID。MCP 进程启动前需要三个环境变量：`CANVAS_AGENT_URL`、`CANVAS_AGENT_TOKEN` 和 `CANVAS_AGENT_SESSION_ID`。缺失时说明如何在本机设置并重启 MCP 客户端，不把密钥写进插件源码、页面 URL、对话或公共配置。网页刷新或重新连接后，使用新的连接 ID。

先调用 MCP 只读工具确认目标画布和节点，再进行用户要求的操作。工具仅作用于显式连接的画布；不能凭返回了节点 ID 宣称媒体已经生成。画布默认先建节点、手动生成。用户需要自动生成时使用画布中的设置，提交后用任务查询工具查看状态。外部写操作通过已连接页面确认；不要绕过页面审批或改用数据库直接操作。

页面保持打开。连接失败时先检查本机服务、Origin、本地网络权限和连接 ID，错误说明见工具结果。退出或断开连接后，已经提交的媒体任务仍由后端管理。
