# 全局样式与组件统一复查记录

本次覆盖登录、创作台、画布、工作流、提示词库、素材、用户、角色权限、日志、系统设置和个人中心，在现有未提交修改的基础上完成调整。

修改内容：

- 全局样式：统一中文字体栈、页面留白、圆角、卡片边框与阴影；补齐品牌色、浮层阴影的浅色和深色变量，移除外部字体请求。
- 深色主题：删除依靠全局 `!important` 强制替换普通颜色类的规则，在实际组件中配置主题颜色，修复媒体白色控件被误改的问题。
- 基础组件：统一 22 个 UI 组件。常规按钮、输入框和选择器采用 40px 高度，小按钮采用 32px；统一焦点、禁用、错误和长文本状态。
- 弹层：统一 Dialog、Popover、Select 的外观与视口限制，减少标题多余留白；正文独立滚动，页脚保持可访问，长选项允许换行。
- 共享组件：登录页与导航共用 ThemeToggle；通知与主题切换使用同一个主题订阅；创作区复用 Button、Badge、Checkbox 和 EmptyState。
- 管理布局：素材、用户、日志和工作流共用页面、面板与分页规范；统一筛选、批量操作、内容区的间距；窄屏工具栏允许换行。
- 短屏布局：管理面板保留足够内容空间并允许整页内部滚动，避免筛选和操作区挤掉分页；日志高级筛选限制高度并支持内部滚动。
- 设置与权限：统一设置、个人中心分类导航和卡片留白；角色权限面板使用可收缩列，去除固定超高布局，长用户名和权限说明不会撑开容器。
- 创作布局：统一创作台、画布和工作流的工具栏与面板；修复画布项目菜单宽度、提示词详情在手机上的高度分配和会话操作可达性。
- 交互细节：增加跳转到页面内容的键盘入口，补齐图标和输入控件焦点；遵循减少动态效果设置；日期选择器使用中文。
