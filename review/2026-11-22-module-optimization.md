# 全站模块优化与实施建议

首轮改造落在请求日志、系统设置、登录页、只读分享画布和素材服务。创作台、画布编辑器、工作流和视频契约适合继续做较大的信息架构与代码拆分。它们的入口、子功能、弹窗和验收条件列在下面。优先级按使用频率、可见问题和改动风险排序。

## 页面与业务模块

| 页面 | 幅度 | 建议与验收 |
| --- | --- | --- |
| `/` 首页 | 小 | 已在三种视口验证角色落点和无权限菜单。继续验证会话服务不可用时的恢复与路径保留。 |
| `/login` 登录 | 小，已调整 | 收紧窄屏表单，移除装饰徽标，将页面标题改为“登录”。三种视口已验证记住账号。移动端软键盘与背景图解码量待测。 |
| `/studio` 创作台 | 大 | 工作区保持图片、视频切换清晰，参数按常用和高级组织。覆盖空会话、首屏历史、分页、重命名、删除、清空、编辑回合、参考上传、局部编辑、预览、下载、任务队列与失败续跑。先从 `image/page.tsx` 提取会话历史协调，再提取任务提交与结果持久化，独立测试切换会话、恢复、撤销式取消及失败重试。在长会话基准中测输入延迟与媒体懒加载。 |
| `/image` 旧入口 | 小 | 保留现有创作台跳转，验收查询参数、锚点、返回键及默认路由。 |
| `/canvas` 画布库 | 中 | 将新建与继续创作保持在第一层，导入、导出、重命名、删除集中在项目操作，选中后出现批量操作。Agent 新建、Skill 与素材选择器作为进阶入口。按需读取 Agent 模型数据，保留搜索、选择和加载失败恢复。 |
| `/canvas/editor`、`/canvas/:projectID` 画布编辑器 | 大 | 统一工作区与节点编辑器的操作层级。逐项覆盖文字、图片、视频、音频、全景、导演台、脚本、分组和生成配置节点，以及连线、批次、撤销重做、草稿恢复、拖放、分享、导入导出、预览、裁剪、蒙版、切图、截音与摄像机工具。优先拆持久化和 Agent 会话同步，再拆节点操作编排。以大画布拖动帧时间、更新一个节点的重渲染数量和并发保存冲突作为验收。 |
| `/share/canvas/:token` 只读画布 | 小，已调整 | 平移缩放时复用节点与连线渲染。继续量化大画布轮询的负载，再考虑基于公开画布版本的条件请求。验收鼠标、触控、键盘、媒体预览、适合屏幕与撤销分享后的失效。 |
| `/workflows` 工作流 | 大 | 明确工作流库、新建模板、编辑、运行四个步骤。独立拆分变量表单、运行器、Agent 草稿和批量生成结果，保留必填检查、草稿排序、素材选择、批量提交和失败补跑。量化列表读取全量配置及模板正文的大小，再考虑概要与详情分开。 |
| `/prompt-library` 提示词库 | 中 | 桌面保留分类和详情并排，手机优先浏览列表与单独详情。明确来源错误、无结果、已收藏及已保存反馈，保留搜索、标签、复制和套用到创作台。测量多来源首屏拉取和每项搜索规范化成本。 |
| `/assets` 我的素材 | 中 | 将范围、类型、标签、搜索与批量行动分层。覆盖文本、图片、视频、音频、所有权和公开范围、批量删除及部分失败反馈、媒体预览和标签编辑。先统一列表和选择器的查询数据，再评估服务端摘要分页。 |
| `/assets/new` 新增素材 | 小 | 手机先填表后看预览，保持保存可达。检查四种素材的必填提示、上传失败、填写过程切换类型和退出未保存。 |
| `/assets/:assetID/edit` 编辑素材 | 中，已调整 | 直接读取当前账号的单条素材，区分读取失败、资源不可编辑和保存失败。已验证直接打开、无记录与读取失败重试。 |
| `/users` 用户管理 | 小 | 统一移动列表和桌面表格的状态与操作菜单。覆盖查询、排序、分页、创建、角色变更、启停、删除与批量部分失败。对配额和用量曲线取样，先量化页面聚合耗时。 |
| `/rbac` 角色权限 | 中 | 桌面保持角色列表与权限编辑并排，手机按角色列表和编辑页组织。重点检查分组说明、可搜索的接口权限、长路径、创建、重置、删除与未保存切换。验收普通账号只能看到对应菜单与动作。 |
| `/logs` 请求日志 | 中，已调整 | 高级筛选移入弹窗，补首屏错误与重试。首屏直接读取日志 API，分页沿用本轮查询实际生效的视图，系统默认视图由 API 一并返回。后续可拆列表、筛选和详情，按真实耗时评估常用过滤的数据库下推。验收应用、取消、清空、默认视图、游标翻页、详情与复制。 |
| `/settings` 系统设置 | 中，已调整 | 保留分类导航与固定行动区。日志和媒体统计进入对应分区才加载，普通配置保存结束即反馈。视频契约编辑器单独加载。各子页见下表。 |
| `/profile` 个人设置 | 中 | 保留分区打开状态与草稿。当前多个隐藏分区仍会挂载，适合采用首次访问才挂载并保留草稿的策略，按需要读取个人存储及模型配置。各子页见下表。 |
| `*` 无效地址 | 小 | 三种视口已验证无效地址和回首页入口。继续核对错误边界重试。 |
| 桌面连接设置 | 小，已调整 | 本机和远程连接共用一套表单。设置读取失败可原位重试，远程连接失败时保留输入地址。短屏验证表单可滚动至提交按钮。 |

## 系统设置与个人设置分区

系统设置九个入口依次为 `#config`、`#model-config`、`#video-model-contracts`、`#image-object-storage`、`#media-storage-governance`、`#announcements`、`#prompt-sources`、`#log-governance`、`#login-page-image`。个人设置五个入口依次为 `#account`、`#appearance`、`#keys`、`#creation`、`#storage`。以下表格按入口顺序列出。

| 分区 | 幅度 | 建议与验收 |
| --- | --- | --- |
| 站点与运行 | 中 | 将站点品牌、连接与数据库、配额和保留策略按使用频率布置。检查代理测试进度、驱动切换、字段错误与配置保存。 |
| 模型服务 | 中 | 统一文本、图片、视频、音频的组、默认值、添加和排序。覆盖模型发现、图片能力弹窗、参数转换编辑和预览，明确空列表与保存失败。 |
| 视频契约 | 大 | 把契约列表、编辑步骤、导入与预览、版本历史和插件生成各自拆为按需面板。验收草稿重开、验证失败定位、批量部分失败、版本回滚、凭据状态和插件生成结果。 |
| 全局存储 | 中 | 策略、服务器本机和外部提供方分别呈现。覆盖 S3、R2、WebDAV 编辑、测试连接、容量统计、启用和默认使用方式。 |
| 媒体清理 | 小，已调整 | 统计独立加载，失败提供重试，刷新期间暂缓清理。覆盖本机四类素材、生成图库、按容量或天数清理、缩略图清理与确认。 |
| 公告发布 | 小 | 列表统一状态、受众、时间和空态，核对发布、编辑、停用、删除与站内公告显示。 |
| 提示词来源 | 小 | 统一启用、排序和来源状态，详情保持来源与内容预览可见。通过失败样例验证重试、回滚与外部来源不可用。 |
| 日志与清理 | 小，已调整 | 统计与保留配置分开加载，失败提供重试。核对每日计划、级别、默认视图、刷新和清理确认。 |
| 登录页展示 | 小 | 将图片上传、替换、拖动取景、缩放和恢复默认统一到既有预览组件。验收桌面登录页与设置预览的一致性。 |
| 账户信息 | 小 | 清晰区分余额没有数据和读取失败。核对长账号名、金额、配额和局部重试。 |
| 外观 | 小 | 两种主题沿用共享按钮语义，验收当前项可识别、键盘切换和主题跨路由持久化。 |
| API 密钥 | 中 | 文本、图片、视频、音频以一致的选中、禁用与保存反馈呈现。核对多选、自定义配置弹窗、删除确认、失败保留和缺失配置提示。 |
| 创作偏好 | 中 | 对模型、画布、接口、指令独立保留编辑状态，按功能复用工作区参数表单。覆盖长指令、默认模型变更、保存返回和不同账号隔离。 |

## 实施顺序

1. 优先拆创作台的会话读写、任务调度和结果持久化，结合长会话与任务变化测量渲染。
2. 画布按保存与恢复、Agent 同步、节点操作三个边界拆，每个边界单独验收撤销、并发与重连。工作流按同样原则先拆运行器与批量草稿。
3. 用真实规模的隔离样本量化可见素材、日志筛选和工作流列表，再决定增加摘要投影、服务端筛选或数据库索引。
4. 继续打磨视频契约、设置和管理页弹窗，桌面、窄屏、短横屏分别走完提交、失败、取消、关闭与返回。

## 验证结果

- Chromium 覆盖 31 个页面或分区状态，包含 19 条路由以及系统设置、个人设置子页。1440×900 浅色、320×568 深色和 844×390 浅色共 93 次页面检查，均无未处理页面异常或整页横向溢出。三个视口另外验证了日志失败重试、筛选取消与焦点恢复、应用和清空筛选、翻页、日志详情、媒体统计重试、清理确认期间阻止关闭及分享画布预览。测试使用隔离的模拟接口。
- 普通系统设置分区首开少发两类治理请求。首次进入日志或媒体治理时只读取该页统计。日志页首开无需读取 `/api/settings`。构建产物中视频契约编辑器独立分包为 43.99 kB gzip。
- 同机使用 2,000 项素材、48 个标签、每标签 1,000 个成员，标签投影基准三轮中位数从约 841 ms 降至 9.8 ms，单次分配由约 2.19 MB 增至 2.67 MB。该基准只测标签投影。
- `npm run lint`、`npm run build`、`npm test -- --timeout 20000` 和 `go test ./...` 通过。Web 测试 1,781 项，Electron、Agent 运行时、画布桥接分别通过 23、54、21 项测试。Go 的未改动包复用有效缓存。Vite 仍报告部分大分包和第三方模块指令警告。
- 使用本地 SQLite 覆盖素材权限、个人分组与标签顺序。MySQL 和 PostgreSQL 集成用例缺少隔离数据库配置，本次跳过。真实上游生成、生产存储及 Windows 安装包未执行。
